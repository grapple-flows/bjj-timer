bjj-timer demo

A free BJJ round timer web component with IBJJF match times, rest periods, a 10-second warning, and fullscreen for a gym TV. The hosted version is at grappleflows.com/timer. Source and docs: github.com/grapple-flows/bjj-timer.

Run npm run build first. This page loads ../dist/bjj-timer.min.js.

Default

<bjj-timer></bjj-timer>

Gym TV: dark, clock and buttons only

<bjj-timer theme="dark" minimal preset="comp-prep"></bjj-timer>

One IBJJF match, custom colors

<bjj-timer belt="blue" minimal style="--bjj-timer-work-color: #1d4ed8"></bjj-timer>
